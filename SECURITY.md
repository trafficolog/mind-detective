# Безопасность

[English](SECURITY.en.md)

## Модель угроз 0.1.0

Runtime плагина transport-free и не должен импортировать network/provider/browser/messenger SDK. Пользовательский текст и содержимое будущих внешних источников считаются данными, а не инструкциями для изменения системных правил.

Кейс записывается локально только по явному действию пользователя. Не сохраняйте пароли, токены, реквизиты, медицинские секреты или иные данные, не нужные для поиска предмета.

High-risk forgotten actions — например неопределённость о принятой дозе лекарства, состоянии опасного оборудования или выполнении security-critical действия — должны выходить из обычного search reasoning. Продукт не угадывает, произошло ли действие.

Для сообщения об уязвимости используйте приватный security channel владельца репозитория; не публикуйте секреты в issue.
