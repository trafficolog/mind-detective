# mind-detective plugin

[Русский](README.md)

The MIND Detective plugin implements transport-free systematic search for misplaced physical items. 0.1.0 exposes exactly five skills around a deterministic Case Controller: safety-first routing, neutral reconstruction, physical SearchCheck planning, explicit resume/handoff, and close/retain/delete.

Runtime is Python-standard-library-only. `.codex-plugin/plugin.json` is the version SSOT. Local persistence is explicit and case-local, with no cross-case learning.
