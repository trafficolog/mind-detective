# Plugin Changelog

[Русский](CHANGELOG.md)

## [0.2.0] — 2026-09-10

The Web/PWA release extends the product with a separate browser/API surface while preserving the canonical Python Case Controller and the plugin's existing safety, provenance, and search invariants. It adds contract traceability for Web requirements, PWA/offline scenarios, browser persistence/export-import contracts, and a provider boundary through a stateless API/LiteLLM integration. The five production skills remain the unchanged plugin surface.

## [0.1.0] — 2026-09-09

Initial production scope: five skills, Case Controller, provenance-aware statements, timeline, guard, SearchCheck log, categorical planner, safety routing, case-local store, and handoff/outcome artifacts.
