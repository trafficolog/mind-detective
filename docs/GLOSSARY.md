# Глоссарий

[English](GLOSSARY.en.md)

- **Case** — канонический агрегат одного поиска.
- **Case Controller** — детерминированный владелец lifecycle/state transitions.
- **Statement source** — `user`, `file`, `assistant`; происхождение высказывания.
- **Statement type** — `recollection`, `habit`, `observation`, `hypothesis`, `search_suggestion`; не является вероятностью истинности.
- **SearchCheck** — фактически выполненная физическая проверка с target/method/result/accessibility.
- **CandidateCheck** — потенциальное физическое действие.
- **Search suggestion** — явно маркированное предложение проверить место, не воспоминание.
- **Free account** — рассказ пользователя своими словами до детального prompting.
- **Handoff** — производный read artifact для продолжения поиска; не новый source of truth.
- **Uncalibrated** — не имеющий эмпирической калибровки как персональная вероятность.
