# Privacy / Конфиденциальность

В 0.1.0 Case создаётся в памяти процесса, а запись на диск выполняется **только по явному действию пользователя** (`save`/`pause`/`retain`). Канонический путь: `.mind-detective/cases/<case-id>/case.json`.

Плагин не создаёт cross-case index, общий профиль, скрытые пользовательские priors или автоматическое обучение на предыдущих кейсах. Resume работает только с явно указанным case id или переданным артефактом. Delete удаляет только выбранный каталог кейса.

Не следует сохранять данные, не необходимые для поиска: credentials, access tokens, платёжные данные, подробные медицинские сведения, полный домашний адрес или иную идентифицирующую информацию без необходимости.

Case artifacts не содержат hidden chain-of-thought, `belief_weight`, POD или location probability. Для будущих connector/surface функций потребуется отдельная privacy/threat-model review.
