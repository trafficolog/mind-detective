## Архитектура
`domain.js` (без DOM/хранилища) ← `MobileScreen.dc.html` (состояние, хранение, разметка). Ошибки ядра — коды (`title_required`…), UI мапит их в русские сообщения.

## Ручные сценарии
- M1 Splash → онбординг → «К делам».
- M2 Создать дело → «Сначала восстановить события».
- M3 Рассказ → сохранить; добавить сведение и 3 события (одно без времени, два с одним точным временем) → видны «неизвестное» и «противоречие».
- M4 «Перейти к физическому поиску» → добавить места.
- M5 «Проверить сейчас» → способ/результат → запись в журнале; повтор помечается.
- M6 «Нашёл» → закрытие, дело неизменяемо.
- M7 Экспорт JSON → удалить → импорт.
- M8 Настройки: без сервера ассистент даёт шаг из контрольного списка, помечен «Только исследование».
- M9 Новое дело «Фото или файл» → источники, цифровые способы проверки, «Файл найден».
- M10 Настройки → адрес n8n и токен → «Предложить следующий шаг» и «Надиктовать» идут через сервер; при остановленном n8n — fallback.
