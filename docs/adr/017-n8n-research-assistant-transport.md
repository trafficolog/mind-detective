# ADR 017 — n8n как необязательный транспорт research-only ассистента

Status: Accepted for `0.5.0` (Glass Modern mobile).

## Context

Handoff выбирает n8n как сервер ассистента и распознавания речи: пользователь хранит в приложении только адрес n8n и токен webhook, а ключи моделей — в n8n Credentials. ADR 012 закрепляет FastAPI → LiteLLM как единственный live-model gateway evaluation-стенда 0.2.0; гейт 0.4.1 держит ассистента реконструкции в статусе research-only.

## Decision

1. Продуктовая оболочка 0.5.0 работает без агента: без сервера предложения строит локальный контрольный список, речь распознаёт браузер.
2. n8n — необязательный, выключенный по умолчанию транспорт. Webhooks: `POST {base}/webhook/md-propose` (`{prompt}` → `{text}`), `POST {base}/webhook/md-transcribe` (multipart → `{text}`). Только `https` или `localhost`.
3. В промпт уходит минимальный контекст: название, тип дела, режим, подтверждённые сведения без гипотез, события, противоречия, места и их состояние. Свободный рассказ и гипотезы не отправляются.
4. Ответ модели проходит детерминированный guard в браузере: только JSON, `kind ∈ {question, check}`, 5–200 символов, без вероятностей/процентов/утверждений о местонахождении, `check` — только в режиме поиска и не для уже проверенного места. Любой отказ, сбой или таймаут 10 с → fallback из контрольного списка с пояснением.
5. Предложение не мутирует Case. «Добавить в список проверки» выполняет `add_search_target` от имени пользователя по его нажатию; «Ответить» открывает форму сведения с пустым текстом. Ассистент реконструкции предлагает только уточняющий вопрос — это совместимо с гейтом 0.4.1 (кандидат-вопрос без канонической мутации).
6. FastAPI/LiteLLM путь ADR 012 остаётся для evaluation-стенда на `/lab` и не удаляется.

## Consequences

- пользователь сам выбирает, куда уходят данные; токен хранится в localStorage этого браузера;
- браузерный guard — дополнительный фильтр, а не замена Python guard evaluation-стенда; эффективность ассистента не заявляется;
- смена модели/провайдера — внутри n8n, контракт приложения не меняется.
