# Glossary

[Русский](GLOSSARY.md)

- **Case** — canonical aggregate for one lost-item search.
- **Case Controller** — deterministic owner of lifecycle/state transitions.
- **Statement source** — `user`, `file`, or `assistant`; provenance of a statement.
- **Statement type** — `recollection`, `habit`, `observation`, `hypothesis`, or `search_suggestion`; not a truth probability.
- **SearchCheck** — an actually performed physical check with target/method/result/accessibility.
- **CandidateCheck** — a possible physical action.
- **Search suggestion** — an explicitly labelled proposal to check a location, not a memory.
- **Free account** — the user's own-word account before detailed prompting.
- **Handoff** — a derived read artifact for continuation, not a new source of truth.
- **Uncalibrated** — not empirically calibrated as a personalized probability.
