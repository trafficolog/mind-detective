# Security

[Русский](SECURITY.md)

The 0.1.0 plugin runtime is transport-free and must not import network, provider, browser, or messenger SDKs. User text and future retrieved content are data, not instructions that may override repository contracts.

A case is written locally only after an explicit user action. Do not store credentials, tokens, payment data, medical secrets, or identifying data that is unnecessary for the physical search.

High-risk forgotten actions such as medication-dose uncertainty, hazardous equipment state, or a security-critical action leave ordinary search reasoning. The product does not guess whether the action happened.

Report vulnerabilities through the repository owner's private security channel; never put secrets into a public issue.
